free osu!collector downloader

Every map from one pasted link.

osu!collect downloads a whole osu!collector collection through nine mirrors and writes the collection.db you import.

In the app: paste the link, pick a folder, press enter.

Download Importing into osu!

how it works

From link to import

1

Paste the collection link

Any osucollector.com collection URL works, and the app asks for the folder to download into.

2

Nine mirrors, automatic failover

A throttled mirror is skipped, so a slow server does not stall the batch.

3

Import into lazer or stable

The collection.db is integrity-checked and imports into your osu! client.

features

What the app does

Free, no account

The official osu!Collector app charges a subscription; osu!collect does not, and logging in is optional.

Collections stay current

Re-check a collection later and only the new or missing maps download.

Search by criteria

Per-difficulty filters find maps with no collection, routed between the osu! api and nzbasic's community database.

Runs in a terminal

Windows, Linux, macOS, started from the shell you already have.
